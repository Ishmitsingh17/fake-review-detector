# Fake & Deceptive Review Detector

An NLP-driven Machine Learning web application to identify fake, automated, or commercially biased product reviews.

## Overview
* **Domain:** Natural Language Processing (NLP) / Consumer Trust Analytics
* **Model:** TF-IDF Feature Extraction with Logistic Classifier
* **Framework:** Streamlit, Scikit-Learn, Pandas, NumPy
* **Objective:** Binary classification of feedback into Genuine vs. Fake/Deceptive

## How to Run Locally
```bash
git clone [https://github.com/](https://github.com/)<your-username>/fake-review-detector.git
cd fake-review-detector
pip install -r requirements.txt
streamlit run app.py
